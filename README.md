# commandbook

commandbook is a multipurpose application for stores with one or multiple storefronts

## Getting Started

1. Clone the project from github: `git clone https://github.com/lilmoopy/commandbook.git`
2. Install the dependencies: `npm install`
3. Start the application: `npm run dev`

## Stack
- Next.JS
- Resend
- Postgres (neon)
- Drizzle ORM
- Tailwind CSS
- ShadcnUI
- Axios
- TypeScript
